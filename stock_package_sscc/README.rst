Stores the SSCC (Serial Shipping Container Code, GS1) of a package, so
that logistic units identified by an SSCC (e.g. pallets) can be told
apart from the ones that have none (e.g. postal parcels), whatever the
package name is.

Use Cases / Context
===================

The SSCC of a logistic unit is usually assigned by the warehouse that
builds it, and has to be sent on in the documents that follow, such as a
despatch advice. The package name can't be used for that: it may or may
not be the SSCC, depending on the unit.

Usage
=====

The field is technical and not displayed: it is filled by integrations
(e.g. a WMS delivery confirmation) and read by exports (e.g. an EDIFACT
despatch advice). A package identified by an SSCC is usually also named
after it.

The SSCC is not copied when a package is duplicated.
